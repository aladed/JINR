# Ablation study: что реально даёт GNN

**val_faulted=534  |  seed=42  |  dataset=v5a_40**

---

## Результаты

| Модель | Hit@1 | Hit@3 | MRR | Что добавлено |
|--------|------:|------:|----:|---------------|
| XGBoost — value only (без temporal) | 43.1% | 54.3% | 0.509 | только текущее значение метрики |
| XGBoost — temporal (с delta_long) | 85.6% | 92.1% | 0.892 | +delta_short, delta_long, rolling_var |
| XGBoost — temporal + соседи (ручной граф) | 86.3% | 91.8% | 0.895 | +mean/max соседей из edge_index |
| **GATv2Hetero (GNN, end-to-end)** | **87.5%** | **92.3%** | **0.903** | message passing по 16 типам рёбер |

---

## Что это означает

### Вклад нашей feature engineering: +42.5pp

```
XGBoost (value only)   43.1%
       ↓ + delta_long / delta_short / rolling_var
XGBoost (temporal)     85.6%    +42.5pp
```

**Без `delta_long` XGBoost — нерабочий метод (43%).** Именно наша работа по  
forensic audit (Фаза 5) — SNR-диагностика, подбор амплитуд, проектирование EMA —  
сделала задачу решаемой для любого метода. Это самостоятельный вклад.

### Вклад структуры графа: +0.7–1.9pp (и качественное превосходство)

```
XGBoost (temporal)              85.6%
XGBoost (temporal + соседи)     86.3%    +0.7pp (ручная агрегация)
GATv2Hetero (GNN)               87.5%    +1.9pp (обученная агрегация)
```

GNN побеждает XGBoost+соседи даже несмотря на то, что XGBoost видит те же соседние  
признаки (мы явно посчитали mean/max по edge_index). Это потому что:

- GNN **учится**, какие типы рёбер важны и с каким весом (attention)
- GNN агрегирует **по 2 слоям** — захватывает соседей соседей
- GNN оптимизирует агрегацию **совместно** с задачей ранжирования

### Структурный тест: network_congestion

| Модель | network_congestion Hit@1 |
|--------|------------------------:|
| XGBoost (value only) | 77.0% |
| XGBoost (temporal, без графа) | 97.7% |
| XGBoost (temporal + соседи, ручной) | 98.9% |
| **GATv2Hetero (GNN)** | **100.0%** |

`network_congestion` — самый **структурный** тип неисправности:  
сам switch-узел может не иметь аномальных собственных метрик,  
но все его downstream-хосты деградируют одновременно.  
GNN — единственный метод, который **никогда** не ошибается на этом типе.

## Итоговая схема вкладов (для диплома)

```
Метод                          Hit@1    Что добавляет
─────────────────────────────────────────────────────────
Наивный XGBoost (value only)   43.1%   ← отправная точка
                                ▲
                              +42.5pp
                                │  наша feature engineering
                                │  (delta_long, EMA, SNR-анализ)
                                ▼
XGBoost (temporal)             85.6%   ← лучший "классический" метод
                                ▲
                              +1.9pp
                                │  структура графа
                                │  (message passing по 16 типам рёбер)
                                ▼
GATv2Hetero v5a_40             87.5%   ← наша итоговая модель
```

**Ключевой тезис**: GNN это не "просто другой классификатор" — это архитектура,  
которая естественно описывает структуру суперкомпьютерного кластера как гетерогенный  
граф и умеет передавать аномальный сигнал вдоль рёбер физической топологии.  
Классические методы этого не умеют без ручного кодирования, и даже с ручными  
признаками соседей уступают GNN, который учится агрегации сам.
